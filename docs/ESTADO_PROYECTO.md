# Estado del proyecto

## Terminado y probado en navegador
Diagnóstico, 8 niveles, 80 lecciones, exámenes, 300 palabras, repaso, improvisación, entrenador, 19 simulaciones, laboratorio, grabaciones, historial, estadísticas, herramientas y ajustes.

## Escrito, sin probar en un dispositivo
Proyecto Android, Vosk, TextToSpeech, referencia sintetizada, recordatorios, respaldo zip y compilación en GitHub Actions.

## Siguiente paso exacto
1. Conectar GitHub y crear el repositorio.
2. Revisar la primera compilación y corregir lo que falle.
3. Instalar el APK y correr el Banco de Pruebas con la lista de 5 minutos.
4. Calibrar umbrales con esos datos.

## Lista de pruebas en el teléfono (5 minutos)
1. Abrir la app y permitir el micrófono.
2. Banco de Pruebas: grabar 60 s y revisar si el texto se parece a lo dicho.
3. Tocar Probar voz.
4. Activar modo avión y repetir la grabación.
5. Cerrar y abrir: las grabaciones deben seguir ahí.
